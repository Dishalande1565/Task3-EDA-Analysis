# Task 3: Exploratory Data Analysis (EDA)
## AI & ML Data Analytics Internship

## Objective
To perform Exploratory Data Analysis on the Iris Dataset
and extract meaningful insights using visualizations.

## Dataset Used
- Iris Dataset (built-in from sklearn)
- 150 rows × 5 columns
- 3 Species: Setosa, Versicolor, Virginica

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- Task3_EDA_Iris.ipynb → Main notebook with all visualizations

## Analysis Performed
1. Univariate Analysis → Histograms & Box Plots
2. Bivariate Analysis → Scatter Plots & Bar Charts
3. Correlation Matrix → Heatmap
4. Pairplot → All features vs All features
5. Count Plot → Species Distribution

## Key Insights
- Petal length & width have 0.96 correlation (very strong)
- Setosa is clearly separated from other species
- Petal features are most useful for classification
- Dataset is clean with no missing values
- Sepal width has few outliers only

## Interview Questions Covered
- Univariate vs Bivariate vs Multivariate Analysis
- How to interpret Correlation Heatmap
- Purpose of Box Plot
- How to identify outliers visually
- Why EDA is important before ML modeling
